# PPT Merge Tool — 設計ドキュメント

- 日付: 2026-06-11
- バージョン目標: v0.1.0(初回リリース)
- ステータス: 設計確定

## 1. 概要

ディレクトリ内に散在する複数の PowerPoint ファイル(`.pptx`)を、ユーザーが指定した順番で 1 つのファイルにマージし、続けて PDF へ変換する GUI ツール。社内の複数 PC で利用する。

### 制約 / 前提

- **実行環境**: Windows PowerShell 5.1(`.exe` 化しない。ウイルスチェックに引っかかるリスク回避のため、Windows 標準の PowerShell で動作させる)
- **GUI**: Windows Forms(.NET Framework 標準同梱、追加インストール不要)
- **マージ / PDF 変換**: Microsoft PowerPoint の COM automation を使用。**各社内 PC に PowerPoint がインストールされていることが前提**
- **配布形態**: `.ps1` + `.psm1` + 起動用 `.bat`。リポジトリを配布する

## 2. 機能要件

| # | 要件 | 決定 |
|---|---|---|
| 順番指定 | マージ順序の指定方法 | リストボックス + 上下移動ボタン |
| ファイル選択 | 対象ファイルの選び方 | フォルダ一括追加 + 個別ファイル追加の両方 |
| 出力 | 保存先・ファイル名 | 保存先フォルダと拡張子なしファイル名を GUI 指定。同名で `.pptx` と `.pdf` を両方出力 |
| PDF 変換 | 変換タイミング | チェックボックスで ON/OFF(デフォルト ON) |
| デザイン | マージ時のテーマ扱い | 各ファイル元のデザイン(テーマ・配色・フォント)をそのまま維持 |
| 処理表示 | PowerPoint 画面 | 非表示でバックグラウンド処理。ツール側に進捗ログを表示 |
| エラー処理 | 読み込み失敗時 | **即座に処理全体を中断**(中途半端な成果物を残さない) |

### 便利機能(採用)

- **① 設定の記憶**: 最後に使った出力先フォルダ・PDF 作成 ON/OFF 等を `%APPDATA%\ppt-merge\settings.json` に保存し、次回起動時に復元
- **② 出力ファイル名の自動初期値**: 起動時に `merged_yyyyMMdd` を初期入力(書き換え可能)
- **③ ドラッグ&ドロップ追加**: エクスプローラーから pptx ファイル/フォルダをツール窓にドラッグして追加

### 非対象(YAGNI)

- スライド枚数プレビュー(COM 起動コストが重いため見送り)
- `.ppt`(旧形式)のマージ対象化(`.pptx` のみを対象)
- 1 つ目のファイルへのデザイン統一機能

## 3. アーキテクチャ

### 技術スタック

- Windows PowerShell 5.1 + Windows Forms(WinForms)
- PowerPoint COM automation(`New-Object -ComObject PowerPoint.Application`)
  - マージ: 新規プレゼンテーションを作成し、選択順に各 pptx を `Slides.InsertFromFile` で追加(元デザイン保持)
  - PDF 変換: `Presentation.SaveAs` で `ppSaveAsPDF`(値 32)形式で保存
  - PowerPoint は非表示で処理

### 処理方式

同期処理 + `[System.Windows.Forms.Application]::DoEvents()`。メインスレッドで順次処理しつつ、要所で DoEvents を呼び UI 更新を確保する。社内資料数本〜十数本のマージでは体感遅延は問題にならない想定。

### コンポーネント

- **CheckedListBox**: チェック ON = マージ対象、OFF = 除外。リストの表示順がマージ順序。表示はファイル名のみ、フルパスは内部保持(ツールチップでフルパス確認)。
- **上下移動ボタン**: 選択項目をリスト内で上下移動。
- **削除 / クリア**: 選択項目の除去 / 全消去。
- **重複追加**: 同一フルパスが既存なら追加せずログ通知。
- **出力先フォルダ / ファイル名 / PDF チェックボックス**: 上記要件の通り。
- **ログ表示**: 読み取り専用の複数行 TextBox。タイムスタンプ付き。
- **ドラッグ&ドロップ**: フォーム/リストへの pptx ファイル・フォルダのドロップで追加。

## 5. コアロジック(`PptMergeCore.psm1`、COM 非依存・テスト対象)

| 関数 | 役割 |
|---|---|
| `Get-PptxFilesInFolder` | フォルダ内の `.pptx` を列挙。一時ロックファイル(`~$` 始まり)、旧形式 `.ppt` を除外 |
| `Test-OutputName` | 出力ファイル名のバリデーション(空・禁止文字 `\ / : * ? " < > \|`) |
| `Resolve-OutputPaths` | 出力先フォルダ + 名前 → `.pptx`/`.pdf` フルパス生成。既存ファイル情報も返す |
| `Get-DuplicatePath` | リストへの重複追加判定 |

## 6. マージ実行フロー(`PptMergeGui.ps1`)

```
1. 入力バリデーション
   - チェック済みファイルが 1 つ以上あるか
   - 出力先フォルダが存在するか / 出力名が妥当か(Test-OutputName)
   - 出力 pptx/pdf が既存なら上書き確認ダイアログ
2. PowerPoint COM 起動（非表示）
3. 新規プレゼンテーション作成
4. チェック済みファイルを表示順にループ:
   - ログ「i/N: ファイル名 を追加中...」
   - Slides.InsertFromFile でマージ（元デザイン保持、絶対パス必須）
   - エラー時（ファイルロック・破損等）→ 即中断
     → ログにエラー表示、COM クリーンアップ、処理終了
   - DoEvents() で UI 更新
5. merged.pptx として保存（全追加成功後にのみ保存）
6. PDF チェック ON なら ppSaveAsPDF で .pdf 保存
7. COM クリーンアップ（Presentation.Close → Application.Quit → ReleaseComObject）
8. 完了ダイアログ
```

### エラー処理・後始末(COM 特有のハマりどころ)

- どの段階で失敗しても **必ず** `try/finally` で PowerPoint プロセスを終了(`Quit` + `ReleaseComObject`)。裏で生き残るのを防ぐ。
- 保存は全ファイル追加成功後にのみ行い、中断時に中途半端な pptx/pdf を残さない。
- `InsertFromFile` の引数は絶対パス必須。日本語パスにも対応する。

## 7. テスト

- フレームワーク: **Pester**(PowerShell 標準的選択)
- 対象: `PptMergeCore.psm1` の純粋ロジック関数(ファイル列挙、名前バリデーション、パス生成、重複判定)
- COM 処理(マージ/PDF 変換)は実際の PowerPoint に依存するため自動テスト対象外。手動確認で担保する。
